# MiriQ — 3쿠션 샷 예측기

공 배치와 방향·힘·당점을 입력하면 물리 시뮬레이션으로 샷 결과(득점 여부, 쿠션 순서, 성공 확률)를 미리 보여주는 웹 앱입니다.

- 물리 엔진: 미끄럼/구름 마찰, 회전, 쿠션 반발, 공-공 충돌(스로우), 스쿼트
- 추천 샷 탐색: 각도(및 당점·힘)를 전수 시뮬레이션하여 득점 구간을 성공 확률 순으로 제시
- 다이아몬드 시스템: 반사각 기하 계산 + 파이브앤하프 환산 + 물리 보정
- 모바일 대응: 세로 화면 테이블 회전, 터치 조작, 미세 조정 조그

```bash
npm install
npm run dev     # 개발 서버
npm run build   # 프로덕션 빌드 (dist/)
```
